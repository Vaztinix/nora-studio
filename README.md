## 🌟 What is Nora?

**Nora** is a high-performance, enterprise-grade, privacy-first Discord ecosystem engineered by **Vaztinix** and the **Nora Studio Team**. Our core mission is not only to be the **#1 Privacy-First All-In-One Discord Bot**, but a guardian that **protects every community that she encounters**. Nora brings together next-generation AI conversational intelligence, forensic server security, multi-mode verification, Roblox identity synchronization, interactive community games, an arcade roguelite Discord Activity, and an obsidian crystal **Liquid Glass Web Dashboard**—all built upon an uncompromising **Zero-Access Architecture**.

Nora supports seamless **Dual Command Routing**: run any feature using native Discord Slash Commands (`/`) or universal text chat prefixes (`n!`, `n?`, or `@Nora`).

```
n!help        /verify        n!rank        /setup        n!afk        /starboard
```

## 🔒 In-Site Security Pass & Advanced Zero-Trust Verification

For servers requiring maximum community protection (such as Milo's World and Nora's Hub), Nora includes the **In-Site Security Pass**—an enterprise-grade, zero-trust gatekeeper engineered to completely eradicate automated raid attacks, spam bots, and malicious ban evasion networks across all communities:

- 🛡️ **Zero-VPN & Proxy Shield**: Automatically inspects connecting network headers, Tor exit nodes, and datacenter ASN classifications. VPNs and proxy tunnels are strictly barred from receiving verification.
- 🧬 **28-Signal Composite Device Telemetry**: Mathematical anti-aliasing variations, WebGL caps, AudioContext waveform hashes, CPU/RAM hardware tiers, display geometry, system font variations, and regional keyboard maps.
- ⚡ **Automated Alt Correlation & Immediate Ban**: When an account attempts verification, its composite device signature is automatically cross-referenced against server ban records. If an alt belongs to a user banned in the guild, **the alt is automatically and immediately banned**.
- 🔒 **Zero-Trust Ephemeral Tickets**: Verification passes are valid for exactly 15 minutes, uniquely tied to the originating Discord session to prevent link sharing.
- 🎨 **Full Dashboard Customization**: Dedicated In-Site Gatekeeper dashboard suite to customize embed titles, descriptions, button labels, emojis, and toggle help explanations with unified redirects for all communities.
- 👤 **Human Non-Inspection Architecture**: Developers and staff possess zero tools to view private personal files or raw biometrics. All attributes are processed purely as mathematical cryptographic checksums in volatile RAM.

## 🛡️ The #1 Top Privacy Bot Choice for Discord

Most Discord bots aggressively hoard server logs, scrape private messages for analytics, or sell server statistics to third-party brokers. **Nora was engineered from day one to reject this paradigm.** 

Nora operates strictly under a verified **Zero-Access Privacy Architecture**:

- 🔒 **Zero Permanent Message Storage**: Messages processed for AutoMod, prefixes, and collaborative games are parsed entirely in volatile RAM and immediately discarded. Nora never dumps chat logs or user text to disk.
- 🚫 **Zero IP Address or Location Surveillance**: Nora strips all IP and geolocation tracking, rejects third-party GeoIP lookups, and never records your physical network location.
- 👤 **"My Data" Total User Sovereignty**: Any user can execute `/mycard` or open the Dashboard **My Data** desk to inspect every single record across servers and execute a 1-click irreversible data purge (`Purge Everything Globally`).
- 🚫 **Zero Developer Backdoors**: Developers have no administrative backdoors to inspect private channels, read guild logs, or harvest server member data.
- 🔐 **End-to-End Credential Encryption**: Sensitive tokens, webhook URLs, and external credentials are cryptographically protected with **AES-256-GCM** encryption before reaching SQLite storage.
- 💻 **100% Data Custody via Self-Hosting**: When you self-host Nora, you own your database entirely. Zero telemetry is sent home.
- 🛡️ **Automated Safety Filters**: Nora's CI/CD pipeline runs `scripts/safety_filter.js` to ensure zero API keys, webhooks, or tokens ever leak into web builds or public distributions.

## 🚀 Quick Self-Hosting

Nora is fully open-source and easy to self-host. For the complete, detailed step-by-step documentation, see [SELF_HOSTING.md](SELF_HOSTING.md).

### 📋 Prerequisites
- **Node.js** `v18.0.0` or higher ([Node.js Download](https://nodejs.org/))
- **Git**
- **Discord Bot Token** from the [Discord Developer Portal](https://discord.com/developers/applications)

### ⚡ 3-Step Setup
```bash
# 1. Clone the repository
git clone https://github.com/Vaztinix/nora-studio.git
cd nora-studio

# 2. Install dependencies & configure .env
npm install
cp .env.example .env

# 3. Build web dashboard assets & start
npm run build
npm start
```

Access your dashboard locally at `http://localhost:3000`.
