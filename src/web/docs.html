System Documentation & Engineering Manual

Comprehensive operational documentation for Nora Studio: Next-Gen Roblox group synchronization, multi-bot Top.gg vote pipelines, sub-4ms AutoMod gateway defense, Starboard v3.0, and leveling progression.

1. Quickstart Setup Guide

Deploy Nora to your Discord community and configure your essential modules in less than 60 seconds:

  1. Authorize Application: Navigate to /install and choose your Discord server. Ensure the bot role is positioned high in role hierarchy.
  2. Interactive Setup in Discord: Run /setup dashboard in any moderator channel to open instant configuration links and role selectors.
  3. Connect Web Dashboard: Visit vaztinix.dev/dashboard to manage Top.gg webhook secrets, Roblox Group ID bindings, custom embeds, and audit logs.
Role Hierarchy Rule: Always place the @Nora role higher than voter reward roles, verified group roles, and muted roles in Discord Server Settings → Roles.

2. Top.gg Vote Rewards & Multi-Bot Tracker

Reward your community members for supporting Nora and any linked custom bots on Top.gg with automatic role awards, customizable Leveling XP, weekend multipliers, and loyalty vote streaks.

Sub-Second Webhook Pipeline: Upvotes are received in real-time via Nora's secure webhook endpoint. If normal bot channel permissions are restricted, Nora falls back to channel webhooks to guarantee delivery.

Webhook Endpoint Configuration

Unified Top.gg Webhook URL 
https://api.vaztinix.dev/api/webhooks/topgg

Multiplier & Streak Formula

Nora calculates voter rewards using a dynamic multiplier matrix:

Factor Bonus Rate Rules & Scheduling
Base XP 150 XP Configurable baseline XP awarded on every verified upvote.
⭐ Weekend 2x 2.0x Multiplier Automatically active Friday 00:00 UTC through Sunday 23:59 UTC.
🔥 Streak Loyalty +25 XP / count Increments on consecutive votes cast within a rolling 36-hour window.
Formula Total XP = (Base XP + [Streak × 25]) × WeekendMultiplier

3. Automated Roblox Group Rank Sync v2.6

Link your Roblox group hierarchy directly to Discord server roles with bi-directional real-time verification:

  • Group Rank Mapping: Bind any numeric Roblox Group ID to Discord roles (Guests, Members, Officers, Developers, Owners).
  • 4-Way Verification: Direct OAuth2, In-Game Code, Bio Keyword verification, and automated nickname sync.
  • Unverified Quarantine: Automatically assign an Unverified role to newcomers to prevent raid attempts until verified.
Setup Command 
/setup verify group_id:12345678 verified_role:@Member unverified_role:@Unverified

4. Leveling & XP Progression Engine

Drive active community interaction with custom leveling rank cards, voice XP rewards, and milestone role unlocks:

  • Chat & Voice XP: Earn 15–25 XP per message with anti-spam cooldowns, plus voice XP every 5 minutes in unmuted channels.
  • Milestone Roles: Grant privilege or cosmetic roles at Level 5, 10, 25, 50, and 100 with optional role stacking.
  • Rank Cards: Users can inspect their progress with /rank or customize their card themes in /rank edit.

5. Support Ticketing & Mod-Mail Engine

Enterprise support ticket workflow with interactive embeds, intake modal forms, and transcript archives:

  • Interactive Panel: Deploy persistent panels with custom buttons (Support, Reports, Appeals, VIP Inquiry).
  • Modal Intake Forms: Collect issue summaries, evidence links, and usernames upfront via pop-up modals.
  • HTML Transcript Archive: Automatically generate and post rich HTML transcripts to your staff log channel when closed.
