Architectural Overview & Documentation

An inside look into Nora Studio's privacy-first Discord ecosystem

Nora Studio is an all-in-one Discord community engagement, automation, and safety ecosystem engineered to provide enterprise-grade moderation, member verification, collaborative chat games, and leveling while maintaining an absolute commitment to user privacy. Following the v2.6 upgrade, Nora supports universal text prefix commands (n!), multi-mode verification engines, an AFK availability notifier, and the real-time Nora Studio web management dashboard.

1. Dual-Execution Engine: Slash & Universal Prefix (n!)

Every command in Nora is accessible via both Discord Slash Commands (/) and standard chat text prefixes (n!, n?, or @Nora), giving your community maximum flexibility on mobile and desktop alike.

  • Zero-Latency Execution: Subcommands, arguments, and mentions (e.g. n!warn @user spamming, n!afk studying, n!rank @user) are resolved instantly.
  • Built-In Shorthand Aliases: Quick shortcuts like n!h (help), n!p (ping), n!lb (leaderboard), n!card (mycard), n!story (onewordstory), and n!w (warn).
  • Consistent Server-Side Security: Member permissions (e.g., Ban Members, Manage Guild) are strictly validated on both prefix and slash commands.

2. Multi-Mode Member Verification (v2.6)

Protect your community against raid bots, alt accounts, and spam rings with our 4-way verification engine, configurable in /setup verify or the web dashboard:

  • 1-Click Instant Button: Frictionless single-click role grant for fast onboarding.
  • Anti-Bot Visual CAPTCHA: High-security distorted SVG/PNG code verification tested against automated bot scripts.
  • Emoji Reaction Verification: Classic pre-reacted embed message where adding a reaction grants the verified role.
  • Roblox Identity Linking: Cryptographic account verification syncing Roblox groups, ranks, and server roles.

3. AFK & Availability Engine

Keep your members informed about chatter availability without chat spam:

  • Instant Setup: Type n!afk [reason] or /afk [reason] to set your status.
  • Auto-Nickname Prefixing: Automatically prepends [AFK] to manageable members' server nicknames.
  • Mention Notifier & Auto-Cleanup: When someone pings an AFK user, Nora replies with their status and auto-deletes the notification to keep channels tidy.
  • Seamless Return: Simply typing a message in any channel immediately removes your AFK status and restores your original nickname.

4. Collaborative Community Games

Boost chat retention with cooperative server-wide mini-games:

  • Sequential Counting: Math-checked sequential counting channel with high-score tracking, anti-double-counting protection, and bonus XP.
  • One Word Story: Multi-author collaborative storytelling with automated punctuation triggers, contributor leaderboards, and milestone archiving.
  • Rock Paper Scissors & Guessing: Quick interactive games against Nora with XP wagering.

5. Consolidated /setup Management Hub

Configure every module in your server from a single organized interface:

  • Organized Module Dashboard: View active status (🟢 On / 🔴 Off) across Welcomer, Leveling, AutoMod, Logging, Games, Verification, and Tickets.
  • Direct Subcommand Routing: Fast jumpers like /setup verify, /setup automod, /setup leveling, and /setup logging.
  • Multi-Audit Log Routing: Direct dedicated log channels for deleted messages, member joins/leaves, voice states, and AutoMod triggers.

6. Privacy-First Data Protocol: "My Card"

Privacy is not an afterthought; it is the foundation of Nora. Nora is built on a "Zero-Access" architecture:

  • User Transparency: The /mycard or n!mycard command provides a real-time window into stored database records.
  • The Sovereign Data Kill Switch: The "Erase Data" button allows any member to immediately and permanently delete their leveling statistics, XP, and Roblox bindings across all Nora nodes.
  • Ephemeral Message Processing: Chat messages are processed in volatile memory for AutoMod and AI triggers and immediately discarded.
