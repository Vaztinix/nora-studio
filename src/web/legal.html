Nora is an automated community moderation, engagement, and server telemetry ecosystem. Our platform provides automated feature systems including:

  • Security & Anti-Raid System (v2.1): Anti-raid gates, min account age filters, avatar requirements, and automated lockdown rules.

Privacy Policy

1. Privacy-First Philosophy

Nora was founded on a strict Zero-Access architecture. We believe that server data belongs to the community. Developers have no backend overrides to read server chat history, read configuration logs, or inspect private member details.

2. Data We Collect & Store

To provide baseline functionality, Nora stores minimal operational configuration data in our local database. This data includes:

  • Guild Configuration Records: Log channel IDs, welcome messages, ticket categories, AutoMod sensitivities, and Starboard settings (including ignored channel lists).
  • Leveling & Engagement Statistics: User XP counts, server levels, custom rank card color hex values, and optional user-uploaded rank card background image URLs or base64 data.
  • Roblox Verification Bindings: Linked Roblox user IDs and verified Discord account associations.
  • Moderation Case Logs: Active user warning counts and issued case reason strings.
  • Integrations: Top.gg integration secret tokens, vote log webhook URLs, and notification preferences.

We do not store message history permanently.

3. Message Processing

Message content is processed in real-time volatile memory strictly to enforce active moderation rules (AutoMod profanity/scam/mentions filters) or supply context to chosen AI engines. This processing occurs in memory and is instantly discarded; it is never written to disk or recorded in permanent storage.

4. AI Data Policies

We do not share your server's logs, member conversations, or leveling data with third parties for training machine learning models. Interactions with AI features are sent only to authorized processing endpoints (Local Nora Engine, OpenAI, or Google Gemini) strictly to generate real-time responses.

5. Web Dashboard & Session Security

The Nora Studio Dashboard connects directly via authorized Discord OAuth2 sessions. We do not permanently store your OAuth2 tokens; tokens are held in encrypted session storage and cleared upon logout. Dashboard operations enforce strict server administrator permission checks, ensuring only authorized administrators can alter guild settings.

6. User Sovereignty & The Data Kill Switch

We respect the right to be forgotten. Users can run the `/mycard` command inside Discord at any time to inspect their stored database record, and click the "Erase Data" button to immediately and permanently delete their leveling statistics, XP, Roblox connections, and warning records across all Nora nodes.

7. Server Data Isolation

Every server operates as an isolated container. Data, logs, settings, Starboard rules, and XP systems generated in one guild are strictly isolated and are never shared or made visible to other servers.

8. Data Erasure upon Bot Removal

If Nora is kicked or removed from a guild, all stored configuration records and log parameters associated with that server ID are scheduled for deletion to keep our databases clean and protect community privacy.
