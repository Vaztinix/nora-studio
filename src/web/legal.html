Privacy Policy

1. Zero-Access & Privacy-First Philosophy

Nora was built with a strict Zero-Access architecture. We believe your server's data, member interactions, and moderation logs belong exclusively to your community. Nora Studio developers do not have backdoor access to inspect private server chat history, read configuration logs, or view private user messages.

2. Data We Collect & Store

To deliver our automated bot services, leveling engines, and dashboard controls, Nora stores minimal, necessary operational records in our secure database:

  • User-Uploaded Media & Custom Images: Custom rank card background images (image files, base64 assets, or URLs from Discord/Klipy CDNs) and custom color hex preferences. These assets are retained persistently in server storage so that your rank card can be dynamically recalled and rendered whenever you or a server member runs /rank or triggers leveling events. They are kept until you choose a different option or request data erasure.
  • Roblox Verification Associations: Linked Roblox User IDs, Roblox usernames, verification timestamps, and server group sync bindings. We never collect, store, or have access to Roblox account passwords or private credentials.
  • Top.gg Telemetry & Voting Records: Discord User IDs, vote timestamps, consecutive streak counts, monthly totals, and opted-in vote reminder preferences sent via Top.gg webhooks.
  • Guild Configuration Records: Server IDs, designated log channels, welcome messages, verification role IDs, ticket categories, AutoMod sensitivities, and Starboard settings.
  • Leveling & Engagement Statistics: User XP counts, guild rank levels, custom rank card colors, and leaderboard statistics.
  • AFK Status Records (Temporary): User ID, voluntary AFK status text, timestamp, and previous nickname. AFK data is automatically and immediately deleted the moment the user sends a new message.
  • Moderation Case Logs: Active user warning counts and issued case reason strings.
  • Collaborative Games Data: Current counting number and high score; completed One Word Story milestone archives.

3. Real-Time Message Processing (No Chat Archiving)

To enforce AutoMod filters (profanity, scam links, invite blocking, mention caps), evaluate prefix commands (n!), and monitor counting channels, message content is processed in real-time volatile RAM memory only. Message content is instantly discarded after evaluation and is never recorded, indexed, or written to permanent disk storage.

4. AI Data & Processing Policies

We do not share, sell, or license your server's conversations, logs, or user information to third parties for training machine learning or AI models. Interactions with AI-assisted features (such as Nora V10 local engine or optional external models) are transmitted to authorized processing endpoints solely to generate real-time answers and are not retained for external training purposes.

5. Web Dashboard & Session Security

Access to the Nora Studio Dashboard is secured exclusively through official Discord OAuth2 authentication. We do not store permanent OAuth tokens; credentials are kept in encrypted, short-lived session storage and cleared upon sign-out. All dashboard administrative requests enforce real-time Discord permission validation to verify the user possesses administrative rights in the target guild.

6. User Sovereignty & The Data Kill Switch (Right to be Forgotten)

We fully respect your right to privacy and data deletion under GDPR, CCPA, and global privacy standards:

  • Inspect Your Data: Run /mycard or n!mycard inside Discord at any time to view your stored leveling statistics, custom card background, and linked Roblox identity.
  • The Data Kill Switch: Clicking the "Erase Data" button on your profile card immediately and permanently purges your XP, leveling statistics, uploaded background images, Roblox links, and warning records across all Nora database nodes.
  • Dashboard Media Removal: You can replace or remove your uploaded rank card background at any time in the dashboard by selecting a built-in solid theme or default background preset.

7. Multi-Tenant Server Data Isolation

Every Discord server operates inside an isolated logical container. Configurations, moderation cases, Starboard reposts, ticket archives, and leveling statistics configured in one server are strictly segregated and are never accessible, visible, or shared with other servers.

8. Automated Data Cleanup upon Bot Removal

If Nora is kicked, banned, or removed from a Discord server, all guild configuration settings and logging channel assignments for that Server ID are automatically scheduled for permanent database removal to protect community privacy.

9. Children's Privacy Compliance

Nora is designed for general audiences and complies with Discord's and Roblox's minimum age requirements. Users must be at least 13 years old (or the minimum legal age of digital consent in their jurisdiction) to use our bot, web dashboard, and linking features. We do not knowingly collect personal data from individuals under 13.

10. Contact & Privacy Inquiries

If you have any questions regarding these Terms of Service, our Privacy Policy, or wish to request manual assistance with data removal, please contact the Nora Studio Team via our official Discord Support Server or by opening a ticket with our team.
