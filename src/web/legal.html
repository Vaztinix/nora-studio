Privacy Policy & Data Handling

Compliance: GDPR (EU) / CCPA (USA) / COPPA Architecture: Zero-Telemetry Commercialization Audit Date: September 2026

At Nora Studio, data privacy and user sovereignty are not secondary features—they are fundamental engineering constraints. This Privacy Policy details the specific categories of metadata collected, the technical reasons for their storage, retention schedules, and your statutory rights regarding data inspection and permanent erasure.

The Zero-Commercialization Guarantee: Nora Studio does NOT sell, rent, lease, or monetize user data under any circumstances. We do not build behavioral advertising profiles, inject tracking beacons, or transfer your community records to data brokers.

1. Data Categories Collected & Technical Justification

In accordance with the principle of Data Minimization (GDPR Article 5(1)(c)), Nora collects only the minimal data strictly necessary to execute its configured Discord functionalities:

Data Category Specific Elements Collected Technical Purpose Retention Window
Discord Structural Metadata Guild IDs, Channel IDs, Role IDs, User Snowflake IDs Required for routing messages, assigning level roles, evaluating permissions, and persisting dashboard settings. Retained while Nora remains in the guild; wiped upon removal or deletion request.
Roblox Verification Mappings Roblox User IDs, Username cache, Group IDs, Numeric rank tiers Enables bi-directional rank-to-role synchronization. We never request, receive, or store Roblox passwords or session cookies. Retained until user unlinks via /verify unlink or executes data purge.
Leveling & Activity Metrics XP numeric total, Level integer, message timestamp counters (for anti-spam rate limiting), voice duration buckets Calculates leveling progression curves and renders customizable rank cards. Retained per guild; purgeable on request via /mycard.
Moderation & Audit Records Case IDs, Target User ID, Moderator ID, Reason text, timestamp, infraction strike count Maintains guild moderation history for administrator review and AutoMod strike escalations. Retained per guild; purgeable by guild owners.
Ticketing Transcripts Message text and author IDs within closed private ticket channels Archives closed customer support tickets for guild staff record-keeping. Stored in secure encrypted buckets for a maximum of 30 days before automatic pruning.
Temporary Connection Security Transient IP address hash (salted and hashed in memory) Protects web dashboard endpoints and API gateways against brute-force authorization attacks. Cleared automatically every 15 to 60 minutes from memory. Never stored in permanent DB records.

2. Legal Bases for Processing (GDPR Article 6)

Nora processes telemetry under the following lawful grounds:

  • Contractual Necessity (Art. 6(1)(b)): To execute the bot commands, role assignments, and dashboard settings requested by server administrators and users.
  • Legitimate Interests (Art. 6(1)(f)): To maintain infrastructure security, mitigate phishing raids, and enforce rate limits against automated exploits.
  • Explicit Consent (Art. 6(1)(a)): When users voluntarily initiate OAuth2 authorization to link their Roblox profile or log into the web dashboard.

3. Security Infrastructure & Sub-Processors

All stored data is protected using enterprise-grade safeguards:

  • Encryption at Rest & In Transit: Communication between user browsers, Discord APIs, and Nora clusters is encrypted using TLS 1.3. Sensitive database records and session tokens are encrypted at rest using AES-256-GCM.
  • Sub-Processor Standards: Nora utilizes top-tier cloud hosting infrastructure (including dedicated bare-metal nodes, PostgreSQL databases with encrypted volume storage, and Cloudflare DDoS filtering). Sub-processors are bound by strict Data Processing Agreements (DPAs).

4. Children's Privacy Protocol (COPPA & Age Verification)

Nora Studio strictly adheres to the Children's Online Privacy Protection Act (COPPA). We do not knowingly collect or solicit personal information from children under the age of 13. Because all account identifiers are purely non-identifying 64-bit numerical snowflakes, Nora does not maintain real names, physical addresses, or phone numbers. If we learn that a user under 13 has interacted with Nora, their numerical mappings are promptly purged from our database.

Roblox Open Cloud & Security Architecture

Protocol: Roblox Open Cloud OAuth2 Standard Key Storage: Zero-Cookie Architecture Verification: Instant Handshake

Nora Studio operates a dedicated, high-security verification and group rank synchronization subsystem designed to connect Roblox identities with Discord servers without ever compromising user credentials or account safety.

1. Roblox Terms of Use Compliance

Our Roblox verification suite adheres fully to the Roblox Terms of Use and Open Cloud Developer Guidelines:

  • No Password or Cookie Ingestion: Nora never asks for, accepts, or stores Roblox account passwords, .ROBLOSECURITY cookies, or private session tokens.
  • Official OAuth2 Protocol: Account verification is executed either via public bio/code verification or official Roblox Open Cloud OAuth2 authentication, where authorization is granted directly on roblox.com.
  • Public API Scopes: Nora only queries publicly accessible endpoints (e.g., group rank integers, user profile display names, and public inventory badges) using authorized API keys.
Cryptographic Verification Handshake: All verification tokens generated for OAuth2 callbacks utilize single-use cryptographic nonces with short 5-minute expiry windows to prevent replay attacks.

2. Group Rank-to-Role Synchronization Boundaries

When guild administrators configure automated group rank synchronization, Nora operates under strict safety constraints:

  • Permission Isolation: Nora can only assign or remove roles that are strictly positioned below the bot's highest role in the Discord server hierarchy. Nora cannot elevate permissions beyond what the server owner has explicitly configured.
  • Audit Trail Persistence: All automatic rank promotions, demotions, and verification role grants are logged to the configured Discord mod-log channel with timestamps and Roblox User IDs.
  • Rate-Limited Group Sweeps: Periodic background group sweeps are throttled to prevent rate-limit flooding against Roblox API endpoints, ensuring maximum platform stability.

3. Multi-Account Binding & Unlinking

Users may link multiple secondary Roblox accounts to their Discord profile via our web portal. However:

  • Only one Roblox account may be designated as the Active Identity for guild role synchronization at any given time.
  • Users retain full autonomy to disconnect or delete their Roblox bindings instantly by using the /verify unlink command in Discord or clicking the "Unlink Account" button on our web portal.

Right to Erasure & Data Deletion Protocol

Standard: GDPR Article 17 / CCPA Section 1798.105 Execution: Instant Self-Service Scope: Complete Database Purge

In accordance with global data protection statutes—including GDPR Article 17 (Right to be Forgotten) and CCPA/CPRA Consumer Privacy Regulations—Nora Studio guarantees that every user and server administrator maintains unconditional, self-service authority to inspect and permanently destroy their data footprint.

1. Instant Self-Service Data Deletion Methods

You do not need to wait for email correspondence to purge your records. You can execute immediate deletion through any of the following methods:

A. Individual User Data Wipe (Discord Slash Command)

Any Discord user can execute the following steps at any time:

  1. Execute the /mycard command in any Discord channel where Nora is present.
  2. Click the red "Erase Data" button on the interactive card.
  3. Confirm the deletion prompt. Nora will immediately and permanently wipe your leveling statistics, voice duration logs, Roblox account associations, and user preference records from our database.

B. Server-Wide Guild Wipe (Administrator Command)

Server owners wishing to purge all community records can:

  1. Execute /settings data-delete inside the server.
  2. Confirm the owner authorization modal. All guild leveling leaderboards, custom command triggers, AutoMod case histories, reaction role mappings, and ticket archives will be irreversibly erased within milliseconds.

C. Roblox Profile Unlinking

To disconnect Roblox verification data exclusively without wiping leveling records, run /verify unlink in Discord or click "Unlink" in the Verification Portal.

Irreversibility of Deletion: Once a data purge is confirmed via /mycard or /settings data-delete, the action is permanent. Cryptographic database records are wiped immediately and cannot be recovered by Nora staff.

2. Formal Data Protection Officer (DPO) Inquiries

If you require a formal GDPR data export, have specialized compliance questions, or wish to submit a written erasure request, you may contact our dedicated Data Protection Officer:

  • Direct Support Email: privacy@vaztinix.dev or vaztinix@gmail.com
  • Official Discord Helpdesk: Open a private data ticket in our Official Support Server.
  • Processing SLA: Written manual data requests are fulfilled within 48 hours, well ahead of the statutory 30-day GDPR requirement.
