# Nora Bot — Human Design Principles & Guidelines

This rule ensures that all messages, embeds, graphics, and web components created for Nora Bot adhere to authentic human-engineering standards and avoid AI-generated tropes.

## Anti-AI Guidelines Summary
1. **No Emoji Prefixing on Field Headers**: Never use emojis at the start of embed field names (e.g. use `Leveling & Rank` instead of `📈 Leveling & Rank Stats`).
2. **Avoid Saturated Neon/Rainbow Gradients**: Use refined obsidian/slate dark canvases with subtle accent borders.
3. **Natural Engineering Tone**: Keep descriptions direct, informative, and concise. Never use corporate hype or AI buzzwords ("fine-tuning next-generation neural engine", "state-of-the-art mainframe").
4. **Clean Action Buttons**: Label interactive buttons with clear verbs (`Refresh`, `Customize`, `Delete Data`) rather than emoji clutter.
5. **Robust ID Binding**: Always bind button custom IDs explicitly (e.g. `mycard_delete_${user.id}`) rather than scraping footer text.
